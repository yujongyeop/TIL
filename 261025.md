# 로그인 로직

```java
public UserLoginResponseDto login(UserLoginRequestDto dto) {
    UsernamePasswordAuthenticationToken authenticationToken = new UsernamePasswordAuthenticationToken(dto.email(),
        dto.password());
    Authentication authentication = authenticationManager.authenticate(authenticationToken);
    CustomUserDetails principal = (CustomUserDetails)authentication.getPrincipal();
    String token = generateToken(principal);
    return userMapper.toLoginResponseDto(principal.getUser(), token);
}
```

# 로그인 테스트 시나리오 작성

## 부하 정도

- 10초 동안 500명의 사용자로 로그인 시도
    - 1초마다 50명을 의미하는 것은 아니며, 10초 총합이 500명이다.
    - 즉, 각 1초마다 요청 수는 다르다.

## 통과 조건

- 실패율 1% 미만
- 처리 시간 3초 미만

## 결과(성공)

| 회차 | 요청 | 실패 | min | p50 | p75 | p95 | p99 | max |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1회차 | 500 | 0 | 88~90ms | 477ms | 905ms | 1,065ms | 1,686ms | 1,838ms |
| 2회차 | 500 | 0 | 88ms | 537ms | 946ms | 1,092ms | 1,873ms | 2,564ms |

# 테스트 시나리오 코드

```java
package com.soompyo.server.loadtest;

import static io.gatling.javaapi.core.CoreDsl.*;
import static io.gatling.javaapi.http.HttpDsl.*;

import java.util.List;
import java.util.Map;
import java.util.stream.IntStream;

import io.gatling.javaapi.core.Body;
import io.gatling.javaapi.core.FeederBuilder;
import io.gatling.javaapi.core.ScenarioBuilder;
import io.gatling.javaapi.core.Simulation;
import io.gatling.javaapi.http.HttpProtocolBuilder;

public class LoginSimulation extends Simulation {

    private static final int ACCOUNTS = 100;
    private static final String PASSWORD = "loadtest1234";

    private static final List<Map<String, Object>> RECORDS = IntStream.range(0, ACCOUNTS)
        .mapToObj(i -> Map.<String, Object>of("email", "loadtest" + i + "@soompyo.com", "password", PASSWORD))
        .toList();
    private static final Body CREDENTIALS = StringBody("{\"email\":\"#{email}\",\"password\":\"#{password}\"}");

    private final FeederBuilder<Object> accounts = listFeeder(RECORDS);

    private final HttpProtocolBuilder httpProtocol = http.baseUrl("http://localhost:8080")
        .contentTypeHeader("application/json")
        .acceptHeader("application/json");

    // 재실행 시 이미 가입된 계정은 409로 응답
    private final ScenarioBuilder signUp = scenario("signUp").feed(accounts)
        .exec(http("signUp").post("/api/v1/users/signUp").body(CREDENTIALS).check(status().in(200, 409)));

    private final ScenarioBuilder login = scenario("login").feed(accounts.circular())
        .exec(http("login").post("/api/v1/users/login")
            .body(CREDENTIALS)
            .check(status().is(200), jsonPath("$.data.accessToken").exists()));

    {
        setUp(signUp.injectOpen(atOnceUsers(ACCOUNTS)).andThen(
            login.injectOpen(stressPeakUsers(500).during(10))))
            .assertions(
                details("login").failedRequests().percent().lt(1.0), // 로그인 실패율 1% 미만
                details("login").responseTime().percentile4().lt(3000) // 로그인 p99 3초 미만
            )
            .protocols(httpProtocol);
    }
}
```
